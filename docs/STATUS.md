## 進め方

指示書(人とレビュー役のAIが作る)→ 実装(VS Code のAI)→ 完了報告 → レビュー → main に取り込み

- 作業は `feature/<内容>` のブランチで行う。main への取り込みはレビューのあと([AGENTS.md](../AGENTS.md) の「2拠点での作業ルール」)
